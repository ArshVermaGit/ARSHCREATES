## 💻 Code Organization

### Comment Structure
Every section follows this pattern:
```html
<!-- ==========================================
     SECTION NAME WITH DESCRIPTION
     - Feature 1
     - Feature 2
     - Feature 3
     ========================================== -->

<!-- Subsection: Component Name -->
<!-- Purpose: What this does -->
<div class="component">
    <!-- Element: Specific part -->
    <element>Content</element>
</div>
```

### ID and Class Naming
```html
IDs:        #camelCase        (e.g., #portfolioModal)
Classes:    .kebab-case       (e.g., .portfolio-card)
Data Attrs: data-kebab-case   (e.g., data-section="games")
```

### Section Markers
Each major section starts with:
```html
<!-- ==========================================
     SECTION NAME
     ========================================== -->
```

Each subsection starts with:
```html
<!-- Subsection: Name -->
```

Each component has:
```html
<!-- Component: Name
     Purpose: Description
     Features: List -->
```

## ✏️ How to Edit

### Change Portfolio Items

**Games/Websites/Apps:**
1. Open `js/data.js`
2. Find `PORTFOLIO_DATA` object
3. Edit the respective array:
```javascript
games: [
    {
        id: 1,
        name: 'Your Game Name',        // ← Edit here
        overview: 'Short description',  // ← Edit here
        description: 'Full description',// ← Edit here
        image: 'images/games/game1.jpg',// ← Edit here
        // ... more fields
    }
]
```

### Change Text Content

**Hero Section:**
```html
<!-- Find line ~220 in index.html Part 1 -->
<h1 class="hero-title">
    Hi, I'm <span>Your Name</span>  <!-- Edit here -->
</h1>
```

**About Section:**
```html
<!-- Find line ~450 in index.html Part 1 -->
<p class="lead">
    Your bio text here...  <!-- Edit here -->
</p>
```

### Add New Section

```html
<!-- Step 1: Add to index.html -->
<section id="new-section" class="section">
    <div class="container">
        <div class="section-header">
            <span class="section-tag">Tag</span>
            <h2 class="section-title">Title</h2>
        </div>
        <!-- Your content -->
    </div>
</section>

<!-- Step 2: Add to navigation -->
<li><a href="#new-section">New Section</a></li>

<!-- Step 3: Add to quick nav -->
<button data-section="new-section">New</button>
```

### Customize Colors

Colors are defined in `css/style.css`:
```css
:root {
  --accent: #A1856D;           /* Change this */
  --accent-secondary: #B8A28A; /* Change this */
  /* ... more colors */
}
```

### Change Images

1. Add image to `images/` folder
2. Update path in HTML or data.js:
```javascript
image: 'images/your-folder/your-image.jpg'
```
